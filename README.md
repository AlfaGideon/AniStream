# AniStream

Персональное Android/PWA-приложение-каталог аниме, манги и ранобэ.

## Каталог и воспроизведение

- AniList, MyAnimeList/Jikan и Kitsu дают только метаданные и обложки; это не ссылки на серии или главы.
- Кнопка просмотра ищет видео по названию через доступные API и показывает только ролики с встраиваемым плеером прямо в AniStream. Платформы не превращаются в сторонние ссылки. VK может отказать методу поиска из-за типа токена (ошибка 1051); YouTube Data API требует отдельный ключ, поэтому поиск доступен только если он уже настроен. Защищённые потоки не извлекаются.
- Читалка открывает локальные изображения и CBZ/ZIP-файлы пользователя. Публичные главы и ссылки на внешние магазины приложение не подставляет; скрейпинг ReManga не реализован.

## Каталоговый backend

Для публичных метаданных приложение использует Cloudflare Worker (`worker/index.js`): он проксирует только разрешённые запросы к AniList, Jikan и Kitsu и кэширует их ответы на edge до 10 минут. Worker нужен как настоящий runtime backend; GitHub Pages раздаёт только статические файлы и backend не заменяет.

GitHub Actions разворачивает Worker перед Android-сборкой и подставляет полученный `workers.dev` URL в приложение. Для этого репозиторию нужны Actions secrets `CLOUDFLARE_ACCOUNT_ID` и `CLOUDFLARE_API_TOKEN` (права токена — Edit Cloudflare Workers). Секреты используются только во время деплоя и не вшиваются в APK. VK-токен пользователя Worker не получает: запросы VK остаются прямыми, а ограничение VK API `1051` backend обойти не может. Поиск YouTube по-прежнему требует пользовательский YouTube API key.

## OTA и подпись APK

В настройках Android есть проверка `releases/latest.json`, загрузка APK с GitHub, сверка SHA-256 и запуск системного установщика. GitHub Actions увеличивает `versionCode` на каждом запуске и обновляет APK-манифест.

Чтобы Android разрешил обновлять APK **поверх установленного**, подпись должна оставаться одной и той же. Для этого workflow использует Actions secrets:

- `ANISTREAM_KEYSTORE_BASE64`
- `ANISTREAM_KEYSTORE_PASSWORD`
- `ANISTREAM_KEY_ALIAS`
- `ANISTREAM_KEY_PASSWORD`

Без них Android-сборка остаётся временно подписанной debug-ключом и OTA установщик будет намеренно заблокирован. Уже установленные APK ранее подписывались разными временными ключами: первый переход на постоянный ключ потребует один раз удалить старую сборку и поставить новую. После настройки постоянной подписи следующие обновления устанавливаются поверх неё. Keystore и его пароли нужно хранить в надёжной резервной копии: если ключ потерять или заменить, Android не разрешит обновить установленное приложение поверх.

Сейчас загрузка latest-манифеста рассчитана на публичную GitHub-ветку. Если сделать репозиторий приватным, для OTA потребуется OAuth-вход в GitHub; токен нельзя безопасно вшивать в APK.

## Разработка и APK

```bash
npm ci
npm run dev
npm test
npm run build
```

Для локальной сборки Android нужны Java 21 и SDK API 35:

```bash
npx cap sync android
cd android && ./gradlew assembleDebug
```

Актуальная debug-сборка: [AniStream-debug.apk](https://raw.githubusercontent.com/AlfaGideon/AniStream/arena/ab870bd3-anistream/releases/AniStream-debug.apk).
