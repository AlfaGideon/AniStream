# AniStream 🎬

Агрегатор **аниме, манги и ранобэ** в духе «КиноПоиск + Re:Манга»: тайтлы объединены во
франшизы, у каждого аниме видны его манга и ранобэ (и наоборот), трейлеры с YouTube
и прямые видео, собственный плеер, ридер и раздел 18+ с возрастным гейтом.

## Стек

- **Vite 6 + React 18 + TypeScript**
- **Tailwind CSS v4** (дизайн-токены через CSS-переменные — три темы меняются на лету)
- **React Router v6**
- Локальное состояние: настройки, закладки, прогресс просмотра и чтения — в `localStorage`
- Арт: сгенерированные постеры (`public/img`) + генеративные обложки в рантайме

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # прод-сборка
npm run typecheck
```

## Единая вселенная (аниме ↔ манга ↔ ранобэ)

Каждый тайтл имеет `franchise` и граф `relations` (`adaptation`, `source`, `sequel`,
`prequel`, `spinoff`). На странице тайтла вкладка **«Связи»** показывает и граф связей,
и все версии франшизы — как у КиноПоиска «похожие», только по-настоящему связанные.

## Раздел 18+

- Выключается/включается в Настройках → «Контент».
- При включении требуется подтверждение возраста (гейт «Мне есть 18»).
- Обложки взрослых тайтлов по умолчанию **размыты** (режим «блюра» тоже настраивается).
- Поиск, каталог и страницы тайтлов уважают эти флаги повсеместно.

## Как подключать реальные источники (парсинг)

Слой провайдеров — интерфейс `ContentProvider` в `src/services/providers/types.ts`:

```ts
interface ContentProvider {
  search(query: string): Promise<TitleItem[]>;
  getTitle(providerId: string): Promise<TitleItem>;
  getEpisodes(providerId: string): Promise<Episode[]>;
}
```

- `mockProvider.ts` — локальный демо-источник (сейчас активен).
- `anilistProvider.ts` — **готовый шаблон** под AniList GraphQL API (CORS открыт,
  ключ не нужен): поиск уже реализован — маппинг в `TitleItem` на месте.
- Аналогично добавляются Shikimori (метаданные + связи), MangaDex (манга/главы),
  AniLiberty/Anilibria и Kodik (видео-источники). Для хентай-источников провайдер
  помечается `adult: true` и попадает под те же гейты 18+.

> ⚖️ Контент принадлежит правообладателям. Проект — демонстрационный агрегатор:
> подключайте только те источники, на использование которых у вас есть права.

## Демо-ограничения (сознательные)

- Серии в плеере идут с публичных sample-стримов (Google sample bucket) — разные серии,
  качество и дорожки подменяются, когда подключены боевые видео-провайдеры.
- Показаны первые 12 серий/60 глав в интерфейсе; каталог — витрина из ~30 тайтлов.
- Страницы ридера — генеративные «кадры»; реальные страницы придут от манга-провайдера.
