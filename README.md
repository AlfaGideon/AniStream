# AniStream

Адаптивное Android/PWA-приложение-каталог аниме, манги и ранобэ.

## Запуск и проверка

```bash
npm ci
npm run dev
npm test
npm run build
```

## Данные и источники

Приложение объединяет публичные каталоги метаданных: AniList GraphQL, MyAnimeList через Jikan, Kitsu. Для карточки аниме AniStream также запрашивает опубликованные Kitsu ссылки на страницы провайдеров. Они открываются на сайте сервиса; доступность зависит от страны и условий платформы. Трейлеры встраиваются по ID YouTube, если его отдаёт каталог.

Интеграция **не предоставляет** сами серии или главы. Встроенный HTML5-плеер поддерживает прямой URL разрешённого MP4/WebM/HLS потока или собственного файла. Для просмотра/чтения можно перейти к платформе из каталога, если ссылка доступна.

Раздел 18+ запрашивается только после возрастного подтверждения; публичные API могут не отдавать NSFW-метаданные без авторизации. На экране «Источники и данные» доступна проверка API с устройства и показ конкретных ошибок сети/ограничений.

Дополнительные метаданные можно подключать адаптером в `src/catalog.js`. У каждого источника своя политика, лимиты запросов и региональная доступность; все API-вызовы выполняются с устройства, поэтому для регионально ограниченных API может понадобиться собственный серверный прокси.

## APK

Android-проект находится в `android/`; квадратная иконка 1024×1024 — `public/anistream-icon-1024.png`. GitHub Actions собирает debug APK и публикует его в `releases/AniStream-debug.apk` при обновлении рабочей ветки.

[Скачать AniStream-debug.apk](https://raw.githubusercontent.com/AlfaGideon/AniStream/arena/a53fe3b3-anistream/releases/AniStream-debug.apk)

Локальная сборка требует Java 21 и Android SDK API 35:

```bash
npm ci
npm run build
npx cap sync android
cd android && ./gradlew assembleDebug
```
