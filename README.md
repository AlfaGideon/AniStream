# AniStream

Адаптивный прототип единого каталога аниме, манги и ранобэ. Интерфейс сделан на Vite, готов для установки как PWA и подготовлен к упаковке в Android через Capacitor.

## Запуск

```bash
npm install
npm run dev
```

Для production-сборки: `npm run build`.

## Android APK

Android-проект лежит в `android/`. Иконка 1024×1024 находится в `public/anistream-icon-1024.png`, подключена в PWA и установлена в launcher-ресурсы Android.

При push в рабочую ветку GitHub Actions собирает `app-debug.apk`. Скачать APK можно в репозитории: **Actions → Build Android APK → последний успешный запуск → Artifacts → AniStream-debug-apk**. Артефакт доступен 30 дней.

Для локальной сборки нужны Node.js, Java 21, Android SDK с API 35:

```bash
npm ci
npm run build
npx cap sync android
cd android && ./gradlew assembleDebug
```

APK будет в `android/app/build/outputs/apk/debug/app-debug.apk`.

## Текущее состояние

- Главная, каталог, поиск, фильтры, избранное и карточки с родственными форматами.
- Демонстрационный плеер, переход к поиску официальных трейлеров YouTube.
- Настройки и явное подтверждение возраста для скрытого раздела 18+.
- PWA-манифест и Capacitor-конфигурация.

Каталог пока демонстрационный, подключения к парсерам/API и реальным видеопотокам нет. Для рабочей версии источники нужно интегрировать через официальные API и лицензированные провайдеры: сайты и каталоги имеют разные условия использования. Веб-скрейпинг и обход ограничений источников здесь не реализованы. Раздел 18+ в прототипе также не содержит явных материалов.
